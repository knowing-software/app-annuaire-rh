# Annuaire RH — Livraison

Bonjour,

Voici l'application Annuaire RH demandée par Meridia. Quelques informations utiles côté
technique :

- l'application est écrite en PHP et nécessite une base MySQL ou MariaDB ;
- le schéma de la base de données ainsi qu'un jeu de données d'exemple se trouvent dans
  `schema.sql` ;
- les paramètres de connexion à la base sont centralisés dans `config.php` — à adapter
  selon votre environnement avant la mise en service ;
- le point d'entrée de l'application est `index.php`.

N'hésitez pas à revenir vers nous en cas de question sur le code.
